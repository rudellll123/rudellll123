Multimodal AI Investigation & Incident Response Platform (in progress)

A flagship agentic AI system that goes beyond my existing CV + RAG + backend projects — it ties them together into one pipeline that can read documents, watch video, listen to audio, and reason across all of it to help investigate incidents and draft a report for human review.

🧠 Orchestration: LangGraph supervisor agent routing to specialized RAG, vision, data, knowledge-graph, and report agents
🔍 Retrieval: Hybrid search (dense embeddings + BM25 + reranking) over Qdrant, plus Neo4j for relationship-aware reasoning
👁️ Vision: YOLO + ByteTrack + VLM-based scene understanding, extending my existing surveillance pipeline
🎙️ Audio: Whisper speech-to-text with TTS for voice-driven queries
⚙️ Backend & Infra: FastAPI, PostgreSQL, Redis + Celery for background jobs, Docker + GitHub Actions, deployed on AWS (S3/ECR/ECS/RDS)
📊 Reliability: RAG/agent evaluation, OpenTelemetry tracing, Prometheus + Grafana dashboards
🧭 Built in phases — agentic foundation → advanced RAG → knowledge graph → vision → audio → MCP tools → production backend → evaluation → observability → cloud deployment → polished dashboard

Human approval stays in the loop — this is an AI-assisted investigation tool, not an autonomous decision-maker.
