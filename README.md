<table>
<tr><td>

<img src="https://img.shields.io/badge/Agentic%20AI-1a7f37?style=for-the-badge" />

My flagship agentic AI project — ties my existing computer vision, RAG, and backend work into one pipeline that reads documents, watches video, listens to audio, and reasons across all of it to investigate incidents and draft a report for human review.

- 🧠 **Orchestration:** LangGraph supervisor agent routing to specialized RAG, vision, data, knowledge-graph, and report agents
- 🔍 **Retrieval:** Hybrid search (dense embeddings + BM25 + reranking) over Qdrant, plus Neo4j for relationship-aware reasoning
- 👁️ **Vision:** YOLO + ByteTrack + VLM-based scene understanding, extending my surveillance pipeline above
- 🎙️ **Audio:** Whisper speech-to-text with TTS for voice-driven queries
- ⚙️ **Infra:** FastAPI, PostgreSQL, Redis + Celery, Docker + GitHub Actions, deployed on AWS (S3/ECR/ECS/RDS)
- 📊 **Reliability:** RAG/agent evaluation, OpenTelemetry tracing, Prometheus + Grafana dashboards
- ✅ Human approval stays in the loop — this is an AI-assisted investigation tool, not an autonomous decision-maker
